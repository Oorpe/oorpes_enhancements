# Oorpe's Enhancements

Opinionated Minecraft data pack for Skyblock and other resource-constrained types of game modes. 

Adds some recipes for smelting and crafting with an emphasis on reducing the amount of time one needs to grind mobs in order to make progress.

## Crafting Recipes added

### Flint Shears

Allow crafting a pair of shears from two flint and two string to give access to leaves and cut grass in early-ish game

### Podzol

Allow manually crafting podzol using any type of leaf block with bonemeal and alternatively gravel or sand. Removes the need to wait for the wandering trader rng to get access to renewable dirt. 

## Smelting recipes added

### Smooth Stone to Gravel

Smelting smooth stone over a long time (300) will cause thermal erosion and cause the stone to crumble.

### Gravel to Sand

The same process of slow thermal erosion can be re-applied to gain access to renewable (albeit fuel- and time-wise pretty expensive) sand.
